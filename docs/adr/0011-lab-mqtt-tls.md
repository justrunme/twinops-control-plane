# ADR-0011: Lab MQTT TLS stub

## Status

Accepted (demo / lab only)

## Context

Milestone 9 calls for stronger MQTT security than anonymous Mosquitto.
Production CA PKI and client certificates are out of scope for the reference
control plane, but demos need a concrete TLS listener to talk about.

## Decision

Ship `deploy/demo/docker-compose.mqtt-tls.yml` with:

- Listener on `:8883`
- Self-signed server cert generated by `scripts/gen_mqtt_tls_certs.sh`
- Certs under `deploy/demo/certs/` (gitignored)
- Anonymous still allowed (ACL remains a separate compose profile)

This is intentionally **not** production TLS: no CA hierarchy, no client certs,
no cert rotation.

## Consequences

- `make mqtt-tls-up` is enough for a lab talking point
- Combine with ACL profile only when both compose files are wired intentionally
- Production MQTT (CA, mutual TLS, credential rotation) stays a non-goal for now
